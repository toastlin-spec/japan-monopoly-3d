# 大富翁・日本之旅 3D

回合制 3D 大富翁桌遊。從台灣出發，一路由北海道玩到沖繩：買下名勝、蓋起旅館和天守閣，在祭典格挑戰小遊戲，讓對手付過路費，最後留在場上的旅人獲勝。

整個遊戲是一個網頁檔（`index.html`），用 [Three.js](https://threejs.org/) r147 繪製 3D 場景，不需要安裝或建置，用瀏覽器打開就能玩。

## 怎麼玩

- **人數**：2–4 人，每個位置可以設定成真人、AI 或關閉。
- **骰子**：可選 1 顆或 2 顆。用 2 顆時擲出雙數可以再擲一次（最多三次）。
- **地產**：停在無主景點可以購買，別人停到你的地要付過路費。
- **加蓋**：再次停在自己的地產時可以加蓋一層：民宿 → 溫泉旅館 → 五重塔 → 天守閣。獨佔整個地區時，空地過路費加倍，而且隨時都能加蓋。
- **主題樂園**：四座樂園不能蓋房，擁有越多座門票越貴（500 / 1000 / 2000 / 4000）。
- **起點**：經過或停留領 2000 元，停留時轉一次幸運轉盤（飛機、扣款、加蓋、拆房）。
- **祭典小遊戲**
  - 青森睡魔祭：停住光點點亮燈籠，點越多獎金越多。
  - 京都祇園祭：按住合掌默數三秒，越準能挑的命運卡越多。
  - 德島阿波舞：跟著太鼓節拍按方向鍵。
- **破產**：現金不夠時可以賣房或抵押，仍付不出就出局。最後留下的人，或回合上限到時總資產最高的人獲勝。

操作提示：空白鍵擲骰子；點棋盤上的景點可以查看地價與過路費；拖曳畫面可以旋轉視角。

## 本機執行

直接用瀏覽器打開 `index.html` 即可。需要網路連線來載入 Three.js 與 Google Fonts。

棋盤路線參考市售「大富翁・日本之旅」桌遊。樂園類景點改用通用名稱，與任何實際品牌無關。
